# 公开版本设计决定

- Tauri/Rust/SQLite + React/TypeScript；commands → services → repo。数据库与网络在 Rust，前端使用类型化 IPC；DTO 由 ts-rs 生成。
- 当前 schema=3，保留 0001/0002/0003。素材先完整落盘再写库，导入校验文件头、拒绝 SVG，ZIP 防路径穿越/压缩炸弹；彻底删除文件进入 _purged 保留30天，目录切换复制 assets。
- v0.5 不增加依赖或迁移，不改神经元渲染接口与背景行为。无模型保持灵感/待办手动流程。
- 显式 target > 前缀 > 模型分类。显式目标最多十条同类型；仅前缀的旧命令保持单条。用户原文和链接由 Rust 校验，日期以本地规则优先，AI 日期仅兜底并标注。
- 目标只决定去向，不提高低置信度字段的可靠性。可靠结果可由用户设置自动保存，其余先编辑确认。Skill/素材空标题链接只在预览补标题，不在自动保存中联网。
- capture.defaultTarget 替代 capture.smartDefault，默认 idea；旧备份忽略旧键。用户选择/前缀同步高于默认设置。
- capture_analyze_stream 使用请求窗口 Channel；只有该路径启用 reasoning_content，普通 AI/旧 capture_analyze 仍丢弃推理。正文与推理分别跨增量脱敏，共享1MB限制。
- 过程仅一轮、仅内存；新轮覆盖旧轮，不写库/备份/日志/剪贴板，不发送成对话上下文。运行收起继续，结束关闭须确认；runId 拒收迟到输出、保存和撤销回写。
- 部分 JSON 只用于可读展示，Rust 完整校验后才可预览保存。结果撤销沿用保存时间/ref资格检查，已编辑/已删除内容保留。
