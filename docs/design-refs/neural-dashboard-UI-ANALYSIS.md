## 控件与反馈

- 导航保持当前页状态，卡片用细边和标题变化指向当前详情；悬停轻微上移，不能冒充选中。
- 搜索无匹配提供清空操作，避免让用户困在空画廊。
- 创建/编辑使用局部表单、提交状态和 Toast；Escape 关闭最内层，背景点击关闭弹层。复杂正文保持常驻编辑，避免所有任务都变成弹窗。
- 创作台 `[[` 关联补全支持方向键、Enter 和 Escape；这是参考的已有功能，Workbench 本轮不新增关联语法。
- 作品库排序、选题状态、转草稿依赖该项目的数据结构；Workbench 延用自己的筛选、转化和保存语义。
- 大多数控件在约 150–250ms 内完成反馈；主要空间过渡有独立的弹簧节奏。参考强调动作与结果的连续性，不适合给每个小控件添加相同的入场动画。

## 首页动画是怎样实现的

`Home.jsx` 和 `NetworkCanvas.jsx` 组合四种技术，而不是单一 Three.js 场景：

1. **视频材质**：中央 `orb.mp4`（1280×720，约 6.017 秒）、外围复用 `jellyfish.mp4`（480×360，约 6.033 秒）。先将视频帧绘入 Canvas，再由样式和透明混合融入背景；检查 currentTime 避免重复绘制相同帧，DPR 上限 2，海报作未解码回退。五只水母复用同一视频，通过相位、倾斜和滤色产生变化。
2. **局部运动**：RAF 中直接更新位置和变换，阻尼弹簧平滑追随目标；避免每帧重建 React 组件。约 110 个尘粒带深度、漂移和透明度差别。
3. **连接与光脉冲**：SVG 三次贝塞尔曲线，细核与较宽透光分层。粒子沿曲线参数行进；入向/出向脉冲有不同相位，方向对应其图数据，不是随机的双向装饰。
4. **状态过场**：`hub → module → note`。中央先显现，外围约 `1s + i×170ms` 进入，标签约 `2s + i×100ms`；模块选择改变构图，条目扇形逐个跟随。Escape 逆向回到上一层。

`NetworkCanvas.jsx` 另负责 BFS 深度展开、90 个入场光点、悬停关联去强调和关系脉冲；它与首页视频材质是两条实现路径。

## 技术、性能与授权

不新增依赖、迁移、字体或运行时视频。主渲染继续 Canvas 2D + 缓存的原创程序表面；每个主题只生成一次膜层，逐帧合成及少量曲线绘制；静态渲染器继续复用一次生成的表面，无 RAF，Canvas 不可用时保留纯 SVG 与独立 HTML 操作层。保留 DPR≤2、空闲降频、离开首页暂停、lite/off 与系统减少动画支持。
