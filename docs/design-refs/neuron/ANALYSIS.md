# 神经元首页：素材分析与实现约定

## 0.4.4 海底影片与黑晶光簇修订（2026-10-22，主材质施工前）

用户提供Steam Workshop本地影片《Wake up》（1781466079），明确要求整个应用使用此片作背景，并解除旧“只用现有语义色”限制。已逐帧查看影片1.2/12/28.8/45.6秒及两份神经元参考的0.12/1.2/2.9/4.6秒：背景由深青海水、透光蓝与暖金小鱼组成；orb是有空隙的黑晶三角网膜、内部金色光簇与移动粒子，jellyfish是倾斜钟形黑晶膜、细丝拖尾和金色局部组织。旧版柔软连续膜的画法与参考差距较大，本轮替换它的主渲染路径。

保留NeuronRenderer接口和六节点坐标，用一个WebGL1上下文与固定960×672图集（中央512²、外围224²）绘制三维三角表面、内部暗色褶片与晶簇、细丝与光点；前后表面分开合成，产生旋转遮挡和局部反射，不给主体套圈。完整档钟体约2.5秒收缩，简洁档减速减幅，off一次取样静止；上下文失效仍回到已有Canvas路径。预算为静态几何缓存、每节点五次有界绘制，避免整屏光线步进；实际数据待验收记录。

全局背景只使用一个静音循环视频，将用户的1920×1080/60秒原片转为1280×720/恒定30fps同内容副本；初始浏览器编码存在帧间隔不均，已改用本机现有FFmpeg转码。保留完整60秒构图和时序，不添加音轨。系统减少动效/off不分配video元素，改用原片静帧；不可见和最小化暂停，播放失败保留静帧。首页保持通透，工作页用深青/浅雾面板保障对比，金色承担主要动作、青光承担环境与连接。

影片及其静帧属于用户提供的第三方本地素材，原project.json注明原画韩一杰；仅进入本地个人交付包，不添加到MIT源码或公开发布。原文件、处理参数和SHA256另记public/scene-media/README.md。orb/jellyfish只研究形态与运动，主材质仍是原创几何与光照；本轮无需新增运行依赖或数据库变更。

## 0.4.3 深海光学与可见运动修订（2026-10-22，渲染前）

用户再次指出松绿配色与近乎静止的运动不符合参考，并明确选择“深海蓝黑＋冰蓝生物光＋少量暖金核心”，允许渲染工具。该选择替代旧方案P5的暂不改色及本文旧色板约定；首页坐标、六节点关系与输入区继续固定，主题设置不被静默改写。

重新检查orb/jellyfish四个时点及连续播放帧：借鉴真实内外遮挡、透射高光、不均匀表面与核心冷暖分离；不以几条细线和轻微整图缩放代替材质。参考媒体只作研究，仍不将PolyForm素材像素或源码引入MIT运行时。

技术选型：原生WebGL1片元着色器生成六格小尺寸材质图集，由现有Canvas2D合成枝干、事件与镜头。中央采用变形隐式表面、前表面光照、内层纤维和偏心暖核；外围采用有厚度的钟形膜、发光褶边和动态口腕。着色器实时改变形态/组织相位，不靠静态纹理缓慢缩放。单一GPU上下文、固定图集约0.28M像素，不渲染整屏高成本体积；无Three.js/渲染库依赖。WebGL创建/编译失败或上下文丢失时继续Canvas材料，off仍为无RAF静态SVG；静态模式可一次性从同一着色器取帧，保留纯SVG兜底。

运动预设：完整档水母约2.5秒收缩一周，半径变化约±14%，触须独立相位随动；中央内部流动与表面转动连续可辨。简洁档减幅减速，关闭档静止；不做频闪或改变业务事件的完成时机。DPR2、离开/最小化暂停、空闲30fps策略保留。

性能预估：图集中央384²、外围5×160²，总计275,456片元/帧；中央最多32步表面求交，外围解析表面加有限口腕，目标活动55–60fps/空闲约30fps。该数字是预算，不是实测，实际WebGL/Canvas降级、上下文丢失、深浅色、0.5秒帧差及动态预览证据写入PROGRESS。

参考API：[WebGLRenderingContext](https://developer.mozilla.org/en-US/docs/Web/API/WebGLRenderingContext)、[上下文丢失模拟](https://developer.mozilla.org/en-US/docs/Web/API/WEBGL_lose_context)。

## 0.4.0 渲染技术（历史）

采用原生 Canvas 2D，零新依赖、零运行时图片/视频。中心是原创的多层透视网膜与偏心细胞核，外节点为带孔隙和细丝的较小膜体；枝干使用曲线纤维束，光点沿枝干传递。颜色只读现有 primary、foreground、background、warning、muted-foreground；素材中的金、蓝等颜色不进入应用。HTML 独立承担按钮、标签、预览和输入。

Canvas 足够绘制六个固定节点，避免为小场景引入 3D 引擎和 GPU 上下文恢复。独立静态 SVG 渲染器实现完全相同的接口，供关闭动效和初始化失败使用。控制器不读取 Canvas 内部状态。实验室通过同一接口驱动主/静态渲染器。

## 0.4.0 性能预估与验证方法（历史）

预估首页独立代码低于 60 KB gzip、Canvas 模块低于 120 KB gzip，视觉素材 0 B。DPR 上限 2；固定数量的网膜点/连线与最多 70 个吸入粒子，避免逐帧 React 更新和 DOM 测量；绘制时复用几何结构。10 秒无交互后 30 fps，离开首页、隐藏/最小化时取消 RAF，恢复后继续时间线。简洁档幅度减半、无常驻光球，关闭档不启动绘制循环。

以上是预算估计，不是实测。在 PROGRESS 单列浏览器/原生 WebView2 的 1440×900 生长帧率、帧耗时、降频/停绘、包体与对照启动结果，记录硬件和 OS 缓存限制。真实视觉质量由实验室及应用人工确认。
