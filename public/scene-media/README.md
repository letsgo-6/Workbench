# Background media

The Windows v0.5.0 installer uses the user-provided Steam Workshop background **Wake up**, item **1781466079**. The supplied metadata credits original art to **韩一杰** (hanyijie.lofter.com / 微博 @韩一杰).

This third-party film and frames are separate from the MIT-licensed application source. Their copyright remains with their respective rights holders. The repository does not contain the original film, derived video/still, or the orb/jellyfish reference media/source. README screenshots show the actual application with demonstration data.

For local source builds, optionally supply `wake-up.mp4` and `wake-up-poster.jpg` in this directory. The verified local video is silent H.264, 1280×720, 30 fps, 60 seconds. Without these optional files the application uses its existing solid-color fallback, with all features available. Keep attribution and any applicable media permissions when reusing third-party assets.
